# Topsy Turvy Game

This is a Python-based minigame created for the kids' TV show Topsy Turvy. Player chooses a locker to enter a randomly selected alternate universe, each with its own difficulty level. Once transported, players must repeatedly click a button to chase down and catch the villain.

## Setup Virtual Environment
Run the code below in terminal to setup virtual environment.
```python3 -m pip install virtualenv
virtualenv venv 
source venv/bin/activate
pip install ipykernel
python -m ipykernel install --user --name=venv
```

## Libraries
Install all required libraries.
```
pip install -r requirements.txt
```
